## Library decision (research: research/viewer-ui-library-decision.md)
Options: (a) vanilla HTML/CSS/JS + CSS tokens + inline Lucide SVG sprite; (b) vanilla helpers (@floating-ui/dom 1.8.0, chart.js 4.5.1); (c) full shadcn/ui (React + Tailwind + Radix + Vite).
Recommendation: (a). Reasons: file:// blocks module scripts, so (c) needs an IIFE bundle + committed built CSS/JS, node_modules, a build step and ~140KB React for ~10 widgets; (b) adds vendored libs for 40 lines of CSS tooltip and two simple canvas/SVG charts. We copy shadcn's design language (zinc neutrals, border + muted-foreground, 0.5rem radius, 36px controls, card pattern) as plain CSS tokens and component classes. No build, no node_modules, `serve` unchanged. Lucide: `lucide`/`lucide-static` 1.60.0, ISC; copy needed SVG paths into ONE inline `<svg style="display:none">` sprite of `<symbol id="i-<name>" viewBox="0 0 24 24">` (stroke=currentColor, stroke-width 2, fill none, round caps/joins) with the ISC licence notice comment preserved; used via `<svg class="icon"><use href="#i-name"/></svg>`. If the implementer finds a real need for (c), STOP and ask; do not switch silently.

## Design system (one place)
- `:root` tokens: colours (--bg, --card, --card-2, --border, --fg, --muted, --accent (subtle jungle green), --good, --bad, --warn, --ring), spacing scale (--s1..--s6 = 4,8,12,16,24,32px), radii (--r-sm,--r-md=8px), font sizes (--fs-xs 12, --fs-sm 13, --fs-md 14, --fs-lg 18, --fs-kpi 28), --icon:16px, --control-h:32px, elevation (--shadow-pop). All CSS values outside `:root` use var(); no ad-hoc inline `style=` in markup (JS may set only dynamic widths/heights via style.width) and no hex colours outside `:root`.
- Documented component classes in viewer/STYLE.md (new file, short): `.btn` (+ `.btn-primary`, `.btn-outline`, `.btn-ghost`, `.btn-icon`), `.input`, `.label`, `.card` (+ `.card-title`), `.kpi`, `.tab`/`.tabs`, `.badge` (+ `.badge-good/.badge-bad`), `.tip` (tooltip), `.info` (info button), `.expander` (details/summary), `.table`, `.scroll` (bounded inner scroll).
- Info buttons and tooltips: `.info` is a `<button type="button" class="btn-icon info" aria-label="About <name>" aria-describedby="tip-<id>">` with Lucide `info` icon, followed by `<span role="tooltip" id="tip-<id>" class="tip">`. Shown on `:hover` AND `:focus-visible`/`:focus-within`, hidden otherwise, Escape hides; works by pure CSS + tiny JS for Escape. One `INFO` text map in JS (key -> text) generates them for KPIs, controls and each tuning knob (knob tooltip = description + "Range min to max, default d" built from /api/config min/max/default). Every icon-only button (play/pause, random seed, run, expand, close, reset) gets aria-label AND a tooltip (`title` is not enough alone).
- Icons (Lucide names): play, pause, dices (random seed), flask-conical or play (run), layers/bar-chart-3 (batch), sliders-horizontal (tuning), list (log), chevron-down/chevron-right (expanders), info, rotate-ccw (reset), trophy/skull (outcome), heart, coins, flask-round (potions), map-pin (zone), activity (replay), layout-dashboard (dashboard), x. ### Addendum 3b: Speed control (user: "should take custom value. and be a logarithmic slider")

## Addendum 4: crisp canvases (user screenshot images/9.png: blurry chart, stretched caption)

Requirements (tests/viewer_canvas_check.mjs + checklist section 17, failing first):
