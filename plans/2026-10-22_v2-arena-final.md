## API contract (tests and code must agree; crate `arena-sim` at v2/sim, lib name arena_sim)
- `arena_sim::rng::Rng::new(seed: u64)`, `next_u64()`, `f32()` in [0,1), `range(lo,hi)`.
- `config::ArenaConfig::default()` fields: tick_hz=30, arena_w=48.0, arena_h=32.0 (tiles), fighter_radius=0.4, max_speed=4.0, max_turn=6.0 (rad/s), max_ticks=1800, n_rays=9, vision_fov=2.094 (rad), vision_range=12.0, max_stamina=100.0, max_hp=100.0.
- `fighter::Role {Hero, Monster}`; `Action {fwd:f32, strafe:f32, turn:f32, attack:bool, block:bool, dodge:bool}`; fwd/strafe/turn in [-1,1].
- `world::Arena::generate(seed: u64, cfg:&ArenaConfig) -> Arena`; `arena.is_blocked(x,y)->bool`; `arena.spawns() -> [(f32,f32);2]`; `arena.reachable(a,b)->bool`.
- `sense::N_IN: usize` (const, 40), `sense::observe(&Match, Role) -> [f32;N_IN]` values within [-1,1]; `sense::ray_hits(...)`.
- `net::N_OUT: usize` = 7; `net::Net::from_genome(&Genome)`; `net.forward(&[f32;N_IN]) -> Action`; `net.reset()`; `genome::Genome {role, weights: Vec<f32>, generation, fitness}` with `to_json()->String`, `from_json(&str)->Result<Genome,String>`, `Genome::random(role, &mut Rng)`.
- `matchup::Match::new(arena:Arena, hero:Genome, monster:Genome, seed:u64, cfg)`; `.step()`; `.finished()`; `.outcome() -> Outcome {HeroWin, MonsterWin, Draw}`; `.hp(Role)`, `.stamina(Role)`, `.pos(Role)`, `.tick()`; `play(arena, hero, monster, seed, cfg) -> MatchResult {outcome, ticks, hero_hp, monster_hp, damage_dealt:[f32;2], log: FightLog}`; `FightLog::to_json()` (frames at tick_hz with pos, facing, hp, stamina, action, state).
- Combat state per fighter: Idle/Windup/Active/Recovery/Blocking/Dodging/Dead; attack windup 6 ticks, active 4, recovery 8, range 1.2 tiles, arc 90 degrees, damage 12; block cuts damage 80 percent inside 120 degree front arc, costs 15 stamina per blocked hit, guard break at 0; dodge costs 30 stamina, 8 ticks i-frames, cooldown 45 ticks; stamina regen 12 per second idle.
- `evolve::Trainer::new(TrainConfig{seed, generations, pop, k_opponents, hof_sample})`, `.run_generation()`, `.hero_champion()`, `.monster_champion()`, `.hall_of_fame(Role)->&[Genome]`, `.stats() -> &[GenStats]` where GenStats has gen, best_fitness[2], mean_fitness[2], win_rate_vs_hof[2], avg_ticks, action_freq {attack, block, dodge}[2]; `Trainer::checkpoint()/resume()`; `training.jsonl` one JSON object per generation; genomes written as `champion_hero_gen_N.json`.
- `campaign` (map plus integration): `jungle::Map::generate(seed,size)` (ported from v1 map.rs, richer: biomes, obstacles, zones); `campaign::run(seed, MapCfg, hero_genomes:&Library, monster_genomes:&Library, permadeath:bool) -> CampaignResult {outcome(won/died/capped), steps, encounters: Vec<Encounter{kind: Grass|Elite|Boss, zone, tile, arena_seed, result: MatchResult}>, map snapshot}`; hero HP persists between encounters with rest at camp (v1 rules ported); permadeath=true ends the run on first hero loss; false respawns at camp as v1. Monster tier from zone: monster nets scale stats by tier (cfg multipliers), same genomes, boss uses stronger stats.
- CLI: `arena-sim train --seed S --gens N --out DIR`, `arena-sim fight --hero F --monster F --seed S --out fight.json`, `arena-sim campaign --seed S --hero F --monster F --permadeath true --out DIR` (writes run.json plus fights/NNN.json).
